# Market-Basket-Analysis
Market Basket Analysis: Groceries (Power BI) is an end-to-end analytics project that identifies which grocery products customers tend to buy together. Using 7,835 transactions across 170 products, the project:

Cleans and transforms raw transaction data with Power Query
Calculates support, confidence, and lift for each product pair using DAX
Presents the results in an interactive Power BI dashboard with a support-vs-lift scatter plot, a product network graph, and a detailed pair-level table
Surfaces key associations (such as Yogurt with soft cheese, curd, and berries, and Whole Milk with vegetables) to support cross-selling, product placement, bundling, and inventory decisions

Tech stack: Power BI Desktop, Power Query, DAX, ZoomCharts, Excel
